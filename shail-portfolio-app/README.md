# Shail Portfolio App

This is the Angular application that powers my personal portfolio website. It is built as a modern, responsive web app and is designed to be deployed to GitHub Pages.

## Purpose

The portfolio showcases:

- My projects and work
- Professional background and experience
- Skills and technologies
- Contact information and social links

## Stack

- Angular 22
- TypeScript
- SCSS
- Angular Material
- GitHub Pages deployment

## Getting started

Install dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm start
```

Then open the app in your browser at `http://localhost:4200/`.

## Build for production

```bash
npm run build
```

The production build output is generated in the `dist/` directory and is ready to be published to GitHub Pages.

## GitHub Pages deployment

This app is prepared to be deployed as a static site using GitHub Pages. After running the production build, deploy the build output to the repository's GitHub Pages host or use a GitHub Actions workflow for automation.

## Project structure

- `src/app/` - application components and pages
- `src/styles/` - global styles and theme tokens
- `public/` - static assets
- `angular.json` - Angular project configuration

## Notes

This project is intended to serve as the public portfolio for my work and professional profile.
